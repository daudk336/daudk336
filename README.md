## Featured work

### Agency Lens
**GoHighLevel account intelligence · Beyond Basic Funnels (BBF)**

Agency Lens is a GoHighLevel browser extension associated with **Beyond Basic Funnels**. Working through an authenticated GoHighLevel session, it audits supported sub-account assets and helps users understand how those assets relate to one another.

- Inspects supported assets including funnels, workflows, tags, custom fields, forms, surveys, and triggers
- Maps relationships across account assets
- Surfaces potential orphaned or broken references for investigation
- Presents health indicators and structured audit reports

**[Explore Agency Lens →](https://beyondbasicfunnels.com/agency-lens)**
