## Featured work

### Agency Lens
**GoHighLevel infrastructure auditing · Beyond Basic Funnels**

Agency Lens is a GoHighLevel browser extension associated with **Beyond Basic Funnels (BBF)**. It uses an authenticated GoHighLevel session to inspect supported sub-account assets, map relationships, and surface potential orphaned or broken references for investigation.

Its focus includes:
- Auditing supported assets such as funnels, workflows, tags, custom fields, forms, surveys, and triggers
- Mapping connections between account assets
- Highlighting potential issues through health indicators and structured reports

[Explore Agency Lens](https://beyondbasicfunnels.com/agency-lens)
